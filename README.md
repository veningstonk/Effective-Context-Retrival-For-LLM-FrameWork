# Effective-Context-Retrival-For-LLM-FrameWork
A five-stage QA pipeline combining TF-IDF retrieval, MiniLM semantic reranking, RoBERTa span extraction, and Knowledge Graph reasoning with Flan-T5 fluency correction. Evaluated on 86,769 SQuAD pairs, achieving 88% retrieval accuracy and 72.5 EM outperforming single-stage baselines on a single GPU.
